##指令说明
插件的核心指令入口为 /kphekili，所有功能均通过该指令的子参数触发，输入指令后会在聊天框输出彩色提示反馈，操作简单直观。除reset指令外，其他指令修改的配置（绑定键、框体位置、锁定状态）都会自动保存，重启游戏后无需重新设置。所有指令执行后都会在聊天框输出彩色提示，方便确认操作是否成功。受魔兽安全框架约束，lock/key/reset 指令在战斗中无法执行，会给出明确提示；hekili/show/resetpos 指令战斗中可正常使用。

=== KP_Hekili_Assistant 指令帮助 ===
/kphekili lock - 锁定/解锁框体，也可以通过色点锁定解锁。
/kphekili key [按键] - 修改绑定键（如 /kphekili key F1，支持组合键 （CTRL-1 ALT-A SHIFT-F等），功能键（F1-F12），字母数字键（A-Z、0-9），鼠标键（MouseWheelUp MouseWheelDown Button3（鼠标中键））
/kphekili hekili - 开关Hekili跟随
/kphekili reset - 重置所有配置
/kphekili show - 显示/隐藏框体
/kphekili resetpos - 重置框体位置到默认，默认在屏幕中偏右下（CENTER, UIParent, CENTER, 235, -210）
/kphekili export - 在聊天框中显示当前职业技能列表
当前绑定键：MouseWheelDown（默认鼠标下滚轮）
Hekili跟随：默认开启

在游戏中查看 ：
- 使用 /run print(#currentActionList) 查看当前技能数量
- 对比KP_ActionList.lua中的初始技能数量，可以知道自动学习了多少技能

核心功能
1. Hekili技能推荐集成 ：自动获取Hekili的最优技能推荐（前提是有HEKILI插件）
2. 自动学习技能 ：第一次遇到新技能时自动添加并保存到技能列表中，无需手动添加
3. 职业隔离 ：每个职业的技能列表独立保存，同一职业的不同角色共享同一个技能列表
4. 持久化保存 ：动态添加的技能会自动保存到数据库，重新加载或重新登录后不会丢失
5. 快速触发 ：通过鼠标滚轮向下（默认，可自定义配置）快速施放当前推荐技能
6. 全职业支持 ：包含所有职业和专精的技能配置
7. 版本适配：支持WLK,MOP,时光等所有HEKILI通用的版本。
8. 动态技能显示 ：根据当前职业、专精和Hekili推荐实时更新技能图标
9. 防卡顿优化 ：使用分帧处理技术避免界面卡顿全性当前应该触发的技能

使用流程
1. 插件加载后自动检测玩家职业
2. 根据职业创建对应的技能层
3. 实时从Hekili获取最优技能推荐
4. 非战斗状态点击图标左上色块自由移动框体位置
5. 玩家使用鼠标滚轮向下（可自定义）触发当前Hekili显示的技能

推荐的工作流程：
1. 使用插件 ：正常使用插件，让插件自动学习技能
2. 定期导出 ：使用 /kphekili export 导出技能列表到聊天框
3. 手动更新 ：将导出的技能列表复制到KP_ActionList.lua文件中
4. 分享给他人 ：可以将更新后的KP_ActionList.lua分享给其他玩家

## ClassActionLists 的作用
ClassActionLists 是必需的 ，它的作用是：

1. 提供默认技能列表 ：当插件第一次加载时，如果没有保存的技能列表，它会使用 ClassActionLists 中的默认技能列表
2. 作为技能库 ：即使启用了 Hekili 跟随，插件也需要在技能列表中找到 Hekili 推荐的技能
3. 支持 VF_Core ：VF_Core 系统需要技能列表来知道要触发哪个技能
## Hekili 跟随的工作原理
当 followHekili 开启时：

1. 插件从 Hekili 获取推荐的技能 ID
2. 在当前技能列表中查找对应的技能索引
3. 更新显示和 VF_Core 来使用这个技能
## 自动学习技能
插件有自动学习技能的功能：

- 当你使用插件时，它会自动添加新遇到的技能到技能列表
- 这些技能会被保存到数据库中
- 下次加载时会使用保存的技能列表，而不是默认的 ClassActionLists
## 总结
1. ClassActionLists 是基础 ：提供初始技能列表，但不是唯一来源
2. Hekili 跟随是核心 ：决定使用哪个技能
3. 自动学习是补充 ：扩展技能列表，适应新技能
所以，即使你设置了只跟随 Hekili，ClassActionLists 仍然是必需的，因为它提供了技能的基础列表和索引系统，让插件能够正确地找到和触发 Hekili 推荐的技能。

如果你发现某些技能在 ClassActionLists 中不存在，插件会在使用过程中自动添加它们，所以你不需要手动修改 ClassActionLists。
